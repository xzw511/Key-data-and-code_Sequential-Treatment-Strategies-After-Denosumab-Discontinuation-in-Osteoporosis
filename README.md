This repository contains the data and analysis code for the meta-analysis and synthesis without meta-analysis (SWiM) of sequential treatment strategies following denosumab discontinuation.
Files
meta_data.xlsx — Data for the meta-analysis
meta_analysis.py — Meta-analysis code
SWiM_data.xlsx — Data for the SWiM analysis
SWiM_analysis.py — SWiM analysis code
Requirements
Python 3 with pandas, numpy, scipy, matplotlib, and openpyxl.
Each analysis script should be placed in the same directory as its corresponding Excel data file before running.
